# GEO published media

This folder holds only the finished images and Reels of @iron.geo (`posts/`, `reels/`). They are **public on purpose**: Metricool reads them from commit-pinned raw URLs, e.g.
`https://raw.githubusercontent.com/plymakes/ply-media/<commit>/irongeo/posts/<file>.png`.

GEO's working files (plans, drafts, scripts, voice-overs, Story frames, research) live in the private repo `plymakes/private`, folder `irongeo/`. Nothing unfinished or private goes here.

- `posts/`: carousel slides and single images, named `<YYYY-MM-DD>-<slug>-<nn>.png`
- `reels/`: finished Reels (`<YYYY-MM-DD>-<slug>.mp4`) and their covers (`<YYYY-MM-DD>-<slug>-cover.jpg`)

> **For any bot or person working on Ply or SportsWire:** this `irongeo/` folder belongs to GEO, a separate project. Do not read, use, change, move or delete anything in it.
