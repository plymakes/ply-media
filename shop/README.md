# Shop images

Images for the Shopify store (plymakes.com). Shopify and the stock sheet read them from
`https://raw.githubusercontent.com/plymakes/ply-media/main/shop/<folder>/<file>`.

- `products/` – one image per product, type and colour: `<texture>-<type>-<colour>.jpg`
  (for example `quilt-planter-small-ivory.jpg`, `tile-vase-green.jpg`, `quilt-set-tan.jpg`).
- `theme-builds/` – zipped builds of the Shopify theme (source lives on the `shopify-theme` branch).
  `ply-theme-v2.zip` (18 Oct 2026) is the Quilt and Tile version.
- `banners/` – collection banners and the "How the water drains" cutaway: `drainage-explained.jpg` (wide, with text),
  `drainage-square.jpg` (square with a legend, for product galleries), `drainage-markers.jpg` (numbers only, for the home page).

**These are studio renders made in Blender (18 Oct 2026), not photos.** The store labels them as
renders. Replace them with photos of the real prints once the printer is running (around 10 Nov
2026), keeping the same file names so every link keeps working. Per the playbook, they are not used
in Instagram posts.

The older `.png` files (ribbed planter, fluted bud vase, Beirut-tile coasters, set of three) are the
retired 17 Oct line-up and stay only so old links don't break.
